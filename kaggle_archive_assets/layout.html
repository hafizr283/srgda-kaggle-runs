05 / READING THE EVIDENCE

Context belongs with the numbers.

Keep these limits in view when comparing or sharing the results.

01

A consistent historical reference

FID/KID use torchvision Inception pool3 and 8k fake / 4k real images. The real reference includes D_val + D_test; it is not an untouched holdout. The real–real diagnostic (~12.74 for students) is not a FID floor. New 2k/5k screens will not be directly comparable.

02

Agreement needs an independent check

The same classifier supplies guidance, health evaluation and snapshot selection. Nudge's 70.70% agreement does not establish semantic class obedience. Independent replay measured 67.6% for the historical nudge and 13.7% for cap30. The verified 200-step screen remains near chance; see the category section.

03

The exported snapshot matters

The 18k cap30 result uses best EMA at logged step 10k; nudge uses raw final. Each arm recorded 17 AMP gradient overflows. Both original joint acceptance targets fail, and this v14 run does not verify the newer guidance-unit repair.

Historical exceptions and source records

Teacher v3 is an invalid black-pool result; repaired conditional EDM v4 (FID 10.36) is a different teacher, not a student improvement. The extra smoke v2 was created by a sharing save and failed; smoke v1 remains the original result. All versions remain linked in the library.
